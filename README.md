# ☕ Cafeteria Bom Sabor

Projeto de uma página web para a **Cafeteria Bom Sabor**, desenvolvido como atividade acadêmica utilizando HTML e CSS.

## 📋 Sobre o projeto

A página apresenta uma cafeteria fictícia, mostrando seus produtos, informações sobre o estabelecimento, endereço e formas de contato.

O objetivo do projeto é praticar a criação de páginas web utilizando **HTML e CSS**, sem a utilização de frameworks.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3

## 📁 Estrutura do projeto

```text
Cafeteria/
│
├── index.html
├── cafeteria.css
└── README.md
```

## 📌 Conteúdo da página

A página possui:

* Cabeçalho
* Menu de navegação
* Apresentação da cafeteria
* Seção "Sobre Nós"
* Seção de produtos
* Endereço
* Informações de contato

## ☕ Produtos

A cafeteria oferece:

* Café Expresso — R$ 5,00
* Capuccino — R$ 8,00
* Sanduíche Natural — R$ 12,00

## ▶️ Como executar

Para visualizar o projeto, basta abrir o arquivo **`index.html`** em um navegador, como Google Chrome, Microsoft Edge ou Firefox.

O arquivo `cafeteria.css` deve permanecer na mesma pasta do HTML para que os estilos sejam carregados corretamente.
